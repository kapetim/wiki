# 🛒 Consumables

**What this is:** the recurring home purchases — a reminder of **which items** to keep in supply, not a ledger. Amounts and prices are situational and calculated when needed; only the item list lives here (generated from `scripts/data/consumables`; edit the JSON, then run `npm run consumables`).

## 🧭 Principle

- **One in use, one spare.** Keep exactly one spare at home; when the in-use one is spent, the spare takes over.
- **No large storage.** Everything here is easy to rebuy — do not stockpile.
- **The spare covers roughly the next week** — unless a good promotion shows up.
- Quantity and price are situational; not tracked here.
