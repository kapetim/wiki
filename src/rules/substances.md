# ☕ Substances

**What this is:** substance guidance — one row per domain, with **difficulty** and **safe limits**. A quick summary first, then a short description per domain. **Not medical advice.**

## 🧭 Summary

<!-- begin table -->
| Domain | Substances | Difficulty | Safe amount / limit |
| --- | --- | --- | --- |
| **Stimulant** | coffee · cocaine · MDMA | low (coffee) · high (cocaine, MDMA) | coffee ≤ ~30 g/day · the rest occasional |
| **Drowsy** | cannabis · alcohol · tobacco | moderate | tobacco ≤ ~3/day · alcohol light · cannabis occasional |
| **Calming** | ketamine | high — emergency only | emergency only, never routine |
<!-- end table -->

## ⚡ Stimulant

Push you to **move** — the relief is putting effort in.

<!-- begin table -->
| Substance | Role | Amount |
| --- | --- | --- |
| **Coffee** | daily driver — tasks | ≤ ~30 g/day |
| **Cocaine** | nitro — emergency only | occasional; never routine |
| **MDMA** | custom gas — social | occasional; respect recovery |
<!-- end table -->

## 🥴 Drowsy

Slow the engine — lower inhibition, pick any path.

<!-- begin table -->
| Substance | Role | Amount |
| --- | --- | --- |
| **Tobacco** | soft brake | ≤ ~3/day |
| **Alcohol** | stupid mode | light only |
| **Cannabis** | waterfall of ideas | occasional |
<!-- end table -->

## 🧯 Calming

Emergency brakes — stop a heartbeat that runs too high.

<!-- begin table -->
| Substance | Role | Amount |
| --- | --- | --- |
| **Ketamine** | handbrake | emergency only |
