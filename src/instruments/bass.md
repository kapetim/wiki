# 🎸 Bass mapping

Low-register anchor map for roots and groove.

## 👀 What to pay attention to when playing

Track these while practicing. Tone is easy (good hardware + EQ setup); **rhythm/groove** is the one to master while keeping notes clean.

- **Right-hand pluck** — fingerstyle, pick, or slap-pop; keep notes even, muting tight (ghost notes).
- **Left-hand fretting** — reach and position; hammer-on, pull-off, slide.
- **Slap & pop** — thumb slap and index-pop attack.
- **Tone** — EQ and drive.
- **Rhythm / groove** — lock with the kick, keep subdivision steady — the hard one.

## 🎹 Core tuning

- Standard 4-string tuning (low to high): `E A D G`.
- Adjacent strings are consistently 5 semitones apart.

## 🎵 Notation rule (always use both)

- Numbered tabs: string + fret movement for groove pattern.
- Letter labels: root note/chord relation (`A`, `E`, `F`, etc.).

Example root walk:

- Numbered pattern on one string: `0 -> 2 -> 3 -> 5`
- Letter result on `A` string: `A -> B -> C -> D`

## 🎵 Playing same song across instruments

1. Extract chord letters from the song.
2. Bass plays root-first version of those letters.
3. Add passing notes but keep bar landing points on chord roots.
4. Verify chord-change moments match guitar/piano changes.

Progression example:

- Song chords: `C - G - Am - F`
- Bass roots: `C - G - A - F` (with optional passing notes between roots)

## 🎵 Example song: Song of Storms (multi-part practice)

- Part A letters: `D F D F D F E C`
- Part B letters: `D F A G F E D C`
- Part C letters: `A C A C A C G E`
- Chord context (loop): `Dm - C - Bb - A`

Numbered tab examples:

```text
Part A
A|--5--8--5--8--5--8------3-
D|-------------------2------

Part B
A|--5--8-----------------8---3-
D|-------7--5--2--5-------------

Part C
A|--12--15--12--15--12--15------
D|-------------------------5--2--
```

Letter mapping:

- `A5 = D`, `A8 = F`, `D2 = E`, `A3 = C`
- `D7 = A`, `D5 = G`
- `A12 = A`, `A15 = C`

Root-line fallback for groove-first version:

```text
A|--5-----3-----1-----0--
 Dm C Bb A
```
