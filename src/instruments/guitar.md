# 🎸 Guitar mapping (electric + acoustic)

Unified guitar map for numbered tabs and letter/chord labels.

## 👀 What to pay attention to when playing

Track these while practicing. Tone is the easy one (good hardware + set it once); **rhythm and wah-wah** are the ones to master while keeping everything else clean.

- **Right-hand strum** — attack pattern: `D D U U D U`, count `1 & 2 & 3 & 4 &`, palm mute `pm`.
- **Left-hand note** — fretted note (`3 = D`) and chord shape (`Dm`), barre position.
- **Note bend** — `½ / 1 / 1½` steps, e.g. `3b→5`; keep the target pitch in tune.
- **Hammer** — hammer-on `3h5` and pull-off `5p3`, even strength.
- **Wah / whammy** — wah-wah pedal on/off; whammy bar moves (dive, flutter).
- **Tone pedal** — effects chain (`OD + delay + reverb`) and gain.
- **Rhythm** — tempo, time signature, feel; the universal skill.

## 🎹 Shared core tuning

- Standard strings (low to high): `E A D G B E`.
- Adjacent-string jump is usually 5 semitones.
- Exception: `G -> B` string jump is 4 semitones.

## 🎵 Shared notation rule (always use both)

- Numbered tabs: string + fret movement.
- Letter/chord label: `A B C D E F G` and chord names (`Am`, `C`, `G`, etc.).

## 🎸 Electric guitar notes

Use this as a practical map from numbered tabs to note/chord letters.

### ⚡ Playing same song across instruments (electric focus)

1. Write the chord progression in letters first.
2. Keep rhythm pattern fixed.
3. On electric, pick positions that minimize jumps.
4. Keep one reference phrase in number form and one in letter form.

Progression example:

- Chords: `Am - F - C - G`
- Electric implementation: choose voicings or power-chord shapes, but keep letter progression unchanged.

## 🎸 Acoustic guitar notes

Same pitch map as electric guitar, different touch/timbre constraints.

### 🎶 Playing same song across instruments (acoustic focus)

1. Start from letter progression (`C - G - Am - F`, etc.).
2. Apply strumming pattern as numeric count (`1 & 2 & 3 & 4 &`).
3. Keep the same chord letters when moving to electric/ukulele/piano.
4. Only change voicing and register.

## 🎵 Example song: Song of Storms (multi-part practice)

Use this for both electric and acoustic guitar.

- Part A letters: `D F D F D F E C`
- Part B letters: `D F A G F E D C`
- Part C letters: `A C A C A C G E`
- Chord context (loop): `Dm - C - Bb - A`

Numbered tab examples (B string focused):

```text
Part A
B|--3--6--3--6--3--6--5--1--

Part B
B|--3--6--10--8--6--5--3--1--

Part C
B|--10--13--10--13--10--13--8--5--
```

Letter mapping:

- `3 = D`, `6 = F`, `5 = E`, `1 = C`
- `10 = A`, `8 = G`, `13 = C`

Acoustic option:

- Play Part A -> Part B -> Part C, then strum the chord loop once.
