# 🎸 Ukulele mapping

Compact 4-string map; great for quick chord transfer.

## 👀 What to pay attention to when playing

Track these while practicing. Tone is easy (strings + EQ if amplified); **rhythm** is the one to master while keeping strum and fretting clean.

- **Right-hand strum** — patterns, finger vs thumb.
- **Left-hand fretting** — chord grips and barres.
- **Hammer / pull** — smooth left-hand articulation.
- **Palm mute / chuck** — percussive strum.
- **Tone** — strings and (if amplified) EQ.
- **Rhythm** — strum feel and timing — the hard one.

## 🎹 Core tuning

- Common tuning: `G C E A` (re-entrant high `G` in standard setup).
- Adjacent strings are mostly 5 semitones apart; `E -> A` is 5 as well.

## 🎵 Notation rule (always use both)

- Numbered tabs: 4-string fret pattern.
- Letter/chord names: keep same harmonic progression as other instruments.

Example:

- Tab shape: `0-0-0-3`
- Chord letter: `C`

## 🎵 Playing same song across instruments

1. Keep the song in chord letters first (`Am - F - C - G`).
2. Convert each chord to ukulele grip.
3. Keep same bar count and rhythm grid.
4. Confirm melody anchor note letters match the source instrument.

## 🎵 Example song: Song of Storms (multi-part practice)

- Part A letters: `D F D F D F E C`
- Part B letters: `D F A G F E D C`
- Part C letters: `A C A C A C G E`
- Chord context (loop): `Dm - C - Bb - A`

Numbered tab examples:

```text
Part A (A string)
A|--5--8--5--8--5--8--7--3--

Part B (A string)
A|--5--8--12--10--8--7--5--3--

Part C (A string)
A|--12--15--12--15--12--15--10--7--
```

Letter mapping:

- `5 = D`, `8 = F`, `7 = E`, `3 = C`
- `12 = A`, `10 = G`, `15 = C`

Chord grips (common ukulele):

- `Dm = 2-2-1-0`
- `C = 0-0-0-3`
- `Bb = 3-2-1-1`
- `A = 2-1-0-0`

Checklist:

1. Keep each section as tab numbers plus letter/chord labels.
2. Note exact repeats (`x2`, `x4`) and where strum-only bars appear.
3. Mark any re-entrant-string voicing adjustments.
