# 🎵 Flute mapping

Single-line melody map, good for clean note-letter hearing.

## 👀 What to pay attention to when playing

Track these while practicing. Gear setup is easy; **breath control and rhythm** are the ones to master.

- **Embouchure** — mouth shape and air focus.
- **Breath control** — support and steady airflow — the hard one.
- **Articulation** — tonguing (legato, staccato, double-tongue).
- **Finger placement** — clean key changes.
- **Vibrato** — controlled pitch shading.
- **Dynamics** — soft to loud.
- **Rhythm** — phrasing and counting — the hard one.

## 🗺️ Core layout

- Think in note letters first (`A..G`) and octave second.
- Natural-note cycle follows mod-7 letter idea.

## 🎵 Notation rule (always use both)

- Numbered pattern: degree or step count (`1 2 3 2 1`, etc.).
- Letter notes: `A B C ...` tied to key center.

Example in `C` major:

- Degree line: `1 2 3 2 1`
- Letter line: `C D E D C`

## 🎵 Playing same song across instruments

1. Pull melody from chords as a letter sequence.
2. Keep rhythm the same while moving instruments.
3. On flute, prioritize melody letters; on strings/keys, keep underlying chord letters.
4. Re-check accidentals where harmony changes key color.

## 🎵 Example song: Song of Storms (multi-part practice)

- Part A letters: `D F D F D F E C`
- Part B letters: `D F A G F E D C`
- Part C letters: `A C A C A C G E`
- Numbered degree lines in D minor:
  - Part A: `1 b3 1 b3 1 b3 2 b7`
  - Part B: `1 b3 5 4 b3 2 1 b7`
  - Part C: `5 b7 5 b7 5 b7 4 2`
- Chord context under melody: `Dm - C - Bb - A`

Practice loop:

1. Play Part A letters slowly.
2. Add Part B, then Part C.
3. Speak degree numbers while playing each part.
4. Repeat A -> B -> C while keeping same letter targets as other instruments.
