# 🌀 Problems

**What this is:** problems with no easy road — split by whether a **definitive fix** exists. **Most have a quick fix; rarely a definitive fix.**

## 🧩 Solvable · unsolvable · unknown

<!-- begin table -->
| Type | Meaning | Example |
| --- | --- | --- |
| **Solvable** | a definitive fix exists — the loop can be closed | **standard flu** — rest and time resolve it |
| **Unsolvable** | no definitive fix — irreversible, unverifiable, or corruptible | **HIV** — managed, not cured |
| **Unknown** | no certain answer — the record can be faked or deleted | **surveillance** — the log is deletable |
<!-- end table -->

## ⚠️ Corruption

> Corruption is its own problem — when the referee, the test, or the auditor is the corrupt party, anything can be argued. Full read:
> [unknown/corruption.md](unknown/corruption.md). **Without corruption, there is a path toward eventual peace.**
