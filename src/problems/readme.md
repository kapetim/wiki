# 🌀 Problems

**What this is:** problems with no easy road — split by whether a **definitive fix** exists. **Most have a quick fix; rarely a definitive fix.**

## 🧩 Solvable vs unsolvable

<!-- begin table -->
| Type | Meaning | Example |
| --- | --- | --- |
| **Solvable** | a definitive fix exists — the loop can be closed | **standard flu** — rest and time resolve it |
| **Unsolvable** | no definitive fix — irreversible, unverifiable, or corruptible | **HIV** — managed, not cured |
<!-- end table -->

## ⚠️ Corruption

With **corruption**, it is hard to solve **any** problem — the referee, the test, or the auditor is the corrupt party, so *anything* can be argued
([unsolvable/justice.md](unsolvable/justice.md), [unsolvable/randomness.md](unsolvable/randomness.md), [unsolvable/accident.md](unsolvable/accident.md)). **Without corruption, there is a path toward eventual peace.**
