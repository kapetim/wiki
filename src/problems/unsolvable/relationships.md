# 💞 Relationships — unsolvable

**What this is:** a relationship problem with **no definitive fix** — loss and grief never fully close.

- **Divorce / breakup** — the shared history stays; the loss is permanent.
- **Bereavement** — the dead do not come back; grief is managed, not cured.
- **A child is permanent** — [parenting.md](parenting.md) is the same shape.
