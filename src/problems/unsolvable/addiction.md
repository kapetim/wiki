# 💊 Addiction — unsolvable

**What this is:** an addiction with **no definitive fix** — craving and relapse risk can stay for life.

- **Permanent dependence** — the substance keeps its hook; abstinence is maintained, not cured.
- **Health damage** — some body cost never returns ([healthcare.md](healthcare.md)).
- **Relapse** — the loop re-opens; there is no "done".
