# 💼 Work — unsolvable

**What this is:** a work problem with **no definitive fix** — some career damage does not repair.

- **Career ruin** — a firing, a scandal, or an age wall can close the door for good.
- **Disability for work** — losing the working body ends that path ([disability.md](disability.md)).
- **Skills decay** — a long gap erodes the very thing that re-opens the door.
