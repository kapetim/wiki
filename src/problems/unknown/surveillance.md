# 📹 Surveillance — the deletable log

**What this is:** an **unknown** problem — things can be tracked, but the log is usually **deleted**, so no record is certain.

- **The standard game:** drive your car → maybe a street camera catches a ticket → then it is a game of complaining and fighting to hide it.
- It reads like a **2D game monitored from cameras on top** — the owner sees everything; the players see the map.
- Evidence is only as good as the disk that holds it ([corruption.md](corruption.md)).
