# ⚠️ Corruption — the corrupt referee

**What this is:** an **unknown** problem — when the referee, the test, or the auditor is the corrupt party, anything can be argued and no answer is certain.

- The last check is often **hired by the same party** — no check at all.
- With corruption it is hard to solve **any** problem — see [surveillance.md](surveillance.md) · [privacy.md](privacy.md) · [underground.md](underground.md).
- **Without corruption, there is a path toward eventual peace.**
