# 🎒 Portable

Handhelds were useful before mobile phones — now a cheap phone has everything. The general-purpose carry device is a phone; dedicated handhelds only earn their place if you travel a lot.

## 📱 Phones

<!-- begin table -->
| Phone | Role | Notes |
| ------- | ------ | ------- |
| Android | Street device | Cheap, easily replaceable; handles general things well |
| iOS | Secure and durable | More security and durability; lower battery |
<!-- end table -->

Android + iOS together cover general things well.

## 🕹️ Handhelds

- Old handhelds (PSP, Nintendo DS) are obsolete — an emulator on an Android phone is cheaper and more fun.
- Modern handhelds (Legion Go, Steam Deck) only if you travel a lot; otherwise a desktop is better value and more configurable.

## ⚡ Power and heat

Any battery-powered machine overheats before a desktop does. Fit a power and thermal tool and default to slow.

<!-- begin table -->
| Mode | Heat and fan | Battery | Use for |
| ------ | -------------- | --------- | --------- |
| Slow | Cool, quiet | Longest | Most things — browsing, code, media |
| Standard | Warm, some fan | Medium | Mixed work on mains |
| Fast | Hot, loud | Drains | Desktop-style heavy loads only |
<!-- end table -->
