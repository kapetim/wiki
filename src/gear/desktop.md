# 🖥️ Desktop

The desktop tower is the default machine — strong hardware, configurable, and the best home for non-Nintendo games.

## 🧭 Must have

<!-- begin table -->
| Part | Why |
| ------ | ----- |
| Strong CPU | Games and builds need headroom; a desktop earns its cost here |
| Discrete GPU | Non-Nintendo games run best on a powerful machine |
| Enough RAM | Cheap insurance for multitasking and game stutters |
| SSD | Everything loads fast; no moving parts |
| Mains power | No battery math — run fast without heat worry |
<!-- end table -->

Configure it — that is the point. See [portable.md](portable.md) for why battery devices default to slow, and [consoles.md](consoles.md) for why a desktop beats a console for non-exclusive games.

## 🧩 Configuration

Configure each machine once, then keep it boring.

**Linux — three users:**

<!-- begin table -->
| User | Use |
| --- | --- |
| owner | Personal data and account ownership |
| contributor | Runs the code the AI writes |
| reviewer | Approves the work; read-mostly |
<!-- end table -->

**Windows — minimal:**

- Steam, Stremio, and games only.
- No code, no GitHub, no dev accounts — as little data as possible.
- Nothing here is precious; wipe and reinstall on suspicion.
