# 🎮 Playing games

What to use, decided by the situation — not by brand loyalty. Ask what you're playing, where, and with which input.

## 🧭 Decision

<!-- begin table -->
| When you want to play… | Use | Why |
| ------------------------ | ----- | ----- |
| An exclusive Nintendo game | Original Nintendo hardware | Best experience — odd content that's hard to replicate |
| Any other game | A desktop machine | Best overall — strong hardware, configurable |
| On the go (a lot of time outside home) | A portable device | Legion Go over PSP-class handhelds |
<!-- end table -->

## 🎮 Input — category → input

<!-- begin table -->
| Game category | Input | Examples |
| --------------- | ------- | ---------- |
| Shooters | Keyboard + mouse | Counter-Strike, Resident Evil |
| Management | Touch screen | Civilization, Mini Metro |
| Everything else | Xbox / PlayStation controller | — |
<!-- end table -->

The Xbox/PlayStation controller is the default for anything that isn't a shooter or a management game — on the desktop, on strong hardware, and on the go alike.

## 💭 Notes

- Consoles as systems (Xbox, PlayStation) are mostly skippable when a capable computer exists.
- An old Nintendo handheld (DS) is expensive — emulating it on a phone is cheaper and more fun.
- A console still makes a fine first device for someone who won't configure anything.
