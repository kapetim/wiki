# 📋 Achievement list — the target list

**What this is:** the **static, hand-edited** list of life achievements to pursue before death — the "what spikes to chase" from [enjoyment](../framework/enjoyment.md) made concrete. Statuses are
rough, honest, and **change by hand** when something pulls or drops. **Metaphor only.**

**How to fill:** when something repeatedly pulls you, add it. When it stops pulling, mark it done, obsolete, or drop it — the list is a **tool, not a trophy**.
