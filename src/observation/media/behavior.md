## 🧲 Incentives and scripts

People do what **pays** (money, status, safety, sex, belonging) under the **script** their group rewards.

<!-- begin table -->
| Visible behavior | Hidden incentive | Script line |
| --- | --- | --- |
| Overwork | Promotion, fear of poverty | “Grind culture” |
| Virtue post | Reputation, in-group rank | “Good person” |
| Gossip | Alliance, threat map | “Just concerned” |
| Compliance | Avoid punishment | “Respect” |
| Risky stunt | Attention, mate signal | “Living life” |
<!-- end table -->

**Same action, different skin** — [masks § pairs](./../masks.md#-paired-opposites-same-trade-different-skin).

## 🔁 Habit loop

```text
Cue → craving → routine → reward → (repeat)
```

<!-- begin table -->
| Lever | Change |
| --- | --- |
| **Cue** | Remove trigger object, change room |
| **Routine** | Substitute action (walk not scroll) |
| **Reward** | Keep small win — brain needs close |
| **Friction** | Make bad harder, good easier |
<!-- end table -->

## ⚡ Cognitive shortcuts

Practical biases — not exam list.

<!-- begin table -->
| Bias | You think… | Often actually… |
| --- | --- | --- |
| **Confirmation** | Evidence supports my take | You filter feed |
| **Sunk cost** | I’ve invested too much to quit | Past spend is gone |
| **Anchoring** | First number frames deal | Salary, price, apology |
| **Fundamental attribution** | They’re rude | They’re late + stressed |
| **Hindsight** | I knew it all along | Memory rewrite |
| **Availability** | Plane crash common | News vivid, base rate rare |
<!-- end table -->

| Style | Moves | Cost |
