# 🌶️ Seasoning

Stock once, lasts many weeks.

## 🌶️ General seasoning blend

Single blend for all dishes (pasta, rice, beans). Adjust ratios to taste.

<!-- begin table -->
| Component | Role | Notes |
| ----------- | ------ | ------- |
| Arisco (or similar) | Base | Salt + garlic + onion — covers the basics |
| Chimichurri powder (dry) | Herbal layer | Dried parsley, oregano, garlic, white pepper |
<!-- end table -->

### 🍽️ Usage by dish

- **Pasta + chicken:** generous amount of the blend
- **Rice + sardines + liver + eggs:** blend + extra chimichurri powder
- **Beans:** blend + optional bay leaf or cumin during cooking

## 🌶️ Optional additions (rotate for variety)

<!-- begin table -->
| Item | Pairs with | Notes |
| ------ | ----------- | ------- |
| Smoked paprika | Chicken, pasta, beans | Adds depth |
| Cumin | Beans, rice, chicken | Warm flavor, great with beans |
| Oregano | Chicken, pasta, sardines | Dried holds well |
| Bay leaf | Beans, rice | Add during cooking, remove before serving |
| Turmeric | Rice | Good with pepper (absorbs better) |
| Dill | Sardines, eggs | Fresh or dried |
| Ginger (powder) | Juice, chicken | Brightens detox juice |
<!-- end table -->

## 🌶️ Daily upper limits

<!-- begin table -->
| Item | Daily limit | Why |
| ------ | ------------- | ----- |
| Salt (incl. from Arisco) | <5 g (~1 tsp) | ~2000 mg Na ceiling — sardine cans add sodium |
<!-- end table -->

## 🌶️ Notes

- Brazilian table salt (including what's in Arisco) is typically iodized — covers the iodine gap.
- No need for separate salt, onion powder, or garlic powder — Arisco covers all three.
- Chimichurri powder already contains white pepper — no need for separate black pepper.
- In the future: consider crafting a custom seasoning blend.
