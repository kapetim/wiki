## 🧠 Powers as cognitive modes

Each power is a **cognitive mode**, not raw strength, and each employer above runs on one:

- **Pattern recognition** — deduces from many possibilities; powerful but **costs time**.
- **Live-stream / VAR** — watches state directly, **no deduction**; fails against **lies**.
- **Combined** — data plus lie-reading; it **flies past the stairs** to the answer.

<!-- begin table -->
| Mode | Read | Fails at |
| --- | --- | --- |
| Pattern recognition | Deduce from many possibilities — thorough, slow | Thin data or missing context |
| Live-stream / VAR | Watch the state directly — no deduction | A lied-about or unrecorded scene |
| Combined | Data plus lie-reading — flies past the stairs | Rare — the most expensive to run |
<!-- end table -->

The Naruto mapping above is this lens applied to a trade: a watcher role sees, a solver role deduces, a hybrid does
both.
