# 🎭 Characters

**What this is:** personality + life reference — one dossier per character, organized by **universe** (franchise), never by media type. Characters from movies, anime, series, and video games.

Each sheet reads like a story: what drives them, how they began, what became of them — and when the medium doesn't tell the full truth, that gap is written down too. A person gets **one** file
even if they span media (Mario = games + movie; Dory = Nemo + her own film) — the universe is the frame, not the medium.

## 🗂️ How it's organized

- **Universe folders** — `characters/<franchise>/` holds everything for that verse, grouped by faction where the cast is big enough. Naruto ([`naruto/readme.md`](naruto/readme.md)) is the
  first: Konoha (Leaf) · Uchiha clan · Sand · Sound · Akatsuki.
- **Inside a universe**, three file kinds:
  - **Individual dossiers** — one per person, named after them; kept when there is substantive standalone personality + life arc (main cast, foils, deep profiles).
  - **Family / clan folders** — blood groups where members each deserve a file but read best as a group (the Uchiha, the Hyūga under Konoha).
  - **Collective files** — thin named characters best read as a team / org / mentor set; one beat per member.
- Solo franchises grow a universe folder once they gain enough dossiers; singletons can sit flat until then.
- **Real-world employers** — [`real-world-jobs.md`](real-world-jobs.md) maps each character to the modern job or institution they'd hold (company, university, hospital, government).

**Cut rule:** substance decides. Deep enough to stand alone → individual or family-member file. Named-with-content but thin → a collective. Contentless mentions → not recorded.

**Relationship with lore:** this folder is the **detailed per-character home**; `interpretations/lore/` keeps the per-series summaries and the theory web. Character-central lore sections
compress to role + `→ sheet` pointers once a sheet exists; theory that *references* characters keeps its tables and links back.

## 🔎 Conventions

- **One person = one file**, named after them (kebab-case), living inside its universe folder. When two unrelated people share a name, suffix the franchise.
- **`Source` is a list**, not a single value — provenance lives in the data, never in the folder path.
- Open every file with a `What this is:` line; wrap every table in the standard begin/end table marker comments.
- Start from the template and delete what doesn't apply — don't leave blanks for life data that doesn't exist.
- **Unknown ≠ none**: a fact the medium never shows is recorded as unknown; the silence is often the point (Shisui's parents).
- **Story vs truth** only when the medium lies, stages, or skips — don't force it onto straightforward characters.
- Keep series summaries and deep theory in `interpretations/lore/`; the dossier holds the distilled reference and links back.
