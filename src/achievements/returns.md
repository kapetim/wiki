# 📈 Returns — the 80/90/100 curve

**What this is:** the **return curve** of mastery and time allocation — where extra effort stops paying, and why **"good enough across many"** usually beats **"perfect at one."** Pairs with
[pleasure.md](../observation/framework/pleasure.md) (frequency) and [mastery-axis.md](../observation/media/mastery-axis.md) (skill axes). **Metaphor only.**

---

## 📈 The 80/90/100 curve

From 0 to ~80% there's a **steep climb** — fast, visible progress. From 80 to 90 it **flattens**. From 90 to 100 it's a **wall**: huge effort, tiny return, often luck-dependent.

<!-- begin table -->
| Stretch | Effort cost | Return | Read |
| --- | --- | --- | --- |
| **0 → 80%** | Low–medium | High | The whole game lives here |
| **80 → 90%** | Medium–high | Medium | Only if the craft *is* the thing |
| **90 → 100%** | Very high | Tiny | Bragging, not living |
<!-- end table -->

**Worked example — Guitar Hero:** 100% FC on *all* songs is a life-dream-grade slog. **80–90% on most songs** brings way more joy for a fraction of the effort — and the gap from 90 to 100 costs almost
everything.

> Acknowledging an achievement exists is fine. Chasing it to 100% is a **different decision** — usually a bad trade.

## 🎯 Generalist vs specialist allocation

<!-- begin table -->
| Shape | Example | Read |
| --- | --- | --- |
| **1/10 in everything** | Sampled, mastered nothing | Widest, weakest — low pleasure |
| **9/10 in one** | Identity lock-in | Highest spike, highest risk — one injury and you're flat |
| **6/10 in many** | "Good enough" generalist | **Very good** — resilient, curious, always useful |
<!-- end table -->

**6/10 across a real set of lanes** (instruments, fitness, languages, games, coding) is a **winning shape** — it keeps the board wide and the spikes frequent. It's the
[Mario generalist axis](../observation/media/mastery-axis.md#-generalist-mario-axis): top ~10% on many lanes beats top ~1% on one, unless you actually love the one.

**Why:** you never know when a **random hobby gives you an idea** — cross-pollination is where new combos come from.

## ⏱️ Time per hobby — personal limits

The same "100% on one thing vs 80% on five" is decided by **your actual time budget** and taste:

<!-- begin table -->
| Hobby | Realistic ceiling |
| --- | --- |
| **Instrument** | ~1h/day — sharp focus, bounded |
| **Video game** | ~12h/day — easy to soak, low setup cost |
| **Reading / study** | ~2–3h/day before diminishing returns |
<!-- end table -->

Each person has their own **limitations and tastes**. The mistake is measuring *commitment* in hours and *value* in hours. Measure **return per hour** — see [budget.md](./budget.md) for the trading
rules.

## 📁 Knowledge as folders — new vs deeper

Knowledge organizes like a **file system**:

- Early: **create folders** — new domains, new hobbies, new instruments.
- Later: **no more folders** — you've accepted the set you can carry.
- Then: **improvements per file** — 80% → 85% across the existing list, and only occasionally a new folder.

<!-- begin table -->
| Phase | Move | Trap |
| --- | --- | --- |
| **Collect** | Open new folders fast | New-folder-holic — 1/10 everywhere |
| **Accept** | Acknowledge the hard limit of folders | Refusing to close any door |
| **Deepen** | Improve each existing file | Chasing 100% on the wrong file |
<!-- end table -->

Keep scanning for new folders — there's a **hard limit**, and once you're near it, dive deeper into the ones you already have.
