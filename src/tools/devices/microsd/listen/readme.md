# 🔊 listen

**What this is:** audio only — soundscapes and music, anything you listen to with no screen. Exempt from the [watch/](../watch/readme.md) video rules; the global card rules are in the [card readme](../readme.md).

## 🗂️ Layout

```text
listen/
└── <file>.mp3   audio-only tracks
```

## 📐 Rules

- Acceptable range: 96–320 kbps. Below 96 is a recycle candidate; above ~320 is over-cap.
- 128–256 kbps is the comfort band.
- No bitrate floor or per-file size cap of its own.

## 🧮 Budget

Soft cap 30 GB for the folder — exceeding it flags the folder; trim or prune.
