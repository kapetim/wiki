# 🖥️ Desktop

The desktop tower is the default machine — strong hardware, configurable, and the best home for non-Nintendo games.

## 🧭 Must have

<!-- begin table -->
| Part | Why |
| ------ | ----- |
| Strong CPU | Games and builds need headroom; a desktop earns its cost here |
| Discrete GPU | Non-Nintendo games run best on a powerful machine |
| Enough RAM | Cheap insurance for multitasking and game stutters |
| SSD | Everything loads fast; no moving parts |
| Mains power | No battery math — run fast without heat worry |
<!-- end table -->

Configure each machine once, then keep it boring — see [machines.md](machines.md) for the setup rules. [portable.md](portable.md) explains why battery devices default to slow; [consoles.md](consoles.md) why a desktop beats a console for non-exclusive games.
